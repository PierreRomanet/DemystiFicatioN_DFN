# DemysTificaioN (DFN) 

## A Discrete Fault Network quasi-dynamic Software


*DemysTificaioN (DFN)* is a quasi-dynamic Boundary Element Code that is modelling fluid diffusion along fault network that is governed by rate-and-state friction.

To get started with DemysTificaioN, see [the documentation](https://pierrerromanet.github.io/DemystiFicatioN_DFN/).



------

## Features

- rate-and-state friction, with velocity cut-offs, aging and slip laws

- heterogeneous frictional properties

- slow and fast, aseismic and seismic slip transients

- non-planar faults (currently limited to variable dip, rectangular elements)

- tectonic and transient loads

- normal stress coupling

- faults surrounded by damaged zones

- Python wrapper, for both input and output
